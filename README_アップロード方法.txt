GitHub Pagesへの更新方法
1. 現在のindex.htmlをバックアップする
2. このフォルダのindex.htmlをGitHubリポジトリの一番上（ルート）にアップロードし、既存のindex.htmlを置き換える
3. Commit changesを押す
4. 公開ページを再読み込みして確認

追加した機能
・サイト上の常時きらめく星とランダムな流れ星
・ボタンやリンクのクリック時に光の粒が広がり、シャリンという合成効果音
・ごまる／しらたまをタップするとハートと専用セリフ、効果音
・流れ星付近をタップすると願い事メッセージ
・多言語メッセージ6言語
・漫画の拡大表示で画像参照が壊れる問題を修正
・画像・BGMはHTMLに内蔵（別フォルダ不要）
・既存のワープとBGM操作を保持

注意
・iPhoneの消音モード、音量、ブラウザの音声許可によって聞こえ方が変わります。音はユーザー操作の後に再生されます。
・画面の動きを減らす設定では粒子演出を抑えます。
・公開端末での最終動作確認は未実施です。
